# Studyhall

Research operations for the lab office. Studies, papers, and grants share one shelf. A study keeps its sites, a milestone stepper, and the documents filed on it.

Signed in as Raghav Poluru, Lab lead.

## Pages

- Studies — open work, with a lead and a standing
- Study — sites, milestones, documents, and the shelf log
- Papers — drafts and published notes
- Grants — amounts, deadlines, and owners, including SH-77
- Labs — rooms and equipment
- Settings — lab name and fiscal year

## Theme

Harbor accent `#0369A1` on a light page. Titles are Lato. Body text is Roboto.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5230/studyhall/studies
