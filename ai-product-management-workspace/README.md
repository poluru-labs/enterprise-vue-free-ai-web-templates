# Specboard

Roadmap for a workplace product. Now, Next, and Later are tabs of spec cards. A spec opens to the problem, the scope, and the owner. The backlog is a tree of areas and stories.

Signed in as Maya Poluru, Product lead.

Pages: Roadmap, spec detail, Specs, Backlog, Releases, new spec, Settings.

Stack: Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Accent `#4338CA`.

Dev server on port 5227. Open http://localhost:5227/specboard/roadmap.
