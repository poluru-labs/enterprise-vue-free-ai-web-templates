# AI Sales Ops

Vue 3 starter for ai sales ops. Built with Vite, Bootstrap, and [@poluru-labs/enterprise-design-system-vue](https://www.npmjs.com/package/@poluru-labs/enterprise-design-system-vue).

## Run

Requires Node.js 20+.

```bash
cd ai-sales-ops-dashboard
npm install
npm run dev
```

Default dev server: http://localhost:5198

| Script | Description |
| --- | --- |
| `npm run dev` | Vite development server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |

## Stack

- Vue 3
- Vite
- Bootstrap 5 + Bootstrap Icons
- `@poluru-labs/enterprise-design-system-vue`
