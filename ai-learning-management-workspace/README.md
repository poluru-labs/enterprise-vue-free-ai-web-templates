# Courtyard

Learning office for short internal courses. The catalog is a grid of course cards. Each card shows a completion meter and a rating. Tabs switch Catalog, Paths, and People. The sidebar stays short.

Signed in as Aditi Poluru, Registrar.

## Pages

- Catalog — course cards, open or all, and a search
- Course — outline, class progress, enroll, and room notes
- Paths — the new-hire order
- People — roster, mean completion, and a person record
- Sessions — book a room with a date and a time
- Settings — reminder and the pass mark

## Stack

Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Light theme, iris `#7C3AED`. Roboto for the interface, Lato for titles.

```sh
npm install
npm run dev
```

The dev server uses port **5222**. Open `http://localhost:5222/courtyard/catalog`.
