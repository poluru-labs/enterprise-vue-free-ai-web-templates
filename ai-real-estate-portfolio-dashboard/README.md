# Lotwell

Portfolio sheet. A stat strip (properties, occupancy, rent collected) sits above the property cards, and the rent table uses that same width. Cards carry a standing rating. No map.

Signed in as Anil Poluru, Portfolio lead.

Pages: Portfolio, property detail, Properties, Leases, Maintenance, new work order, Settings.

Stack: Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Accent `#3F6212`.

Dev server on port 5228. Open http://localhost:5228/lotwell/portfolio.
