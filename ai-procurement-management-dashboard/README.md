# Purchasewell

Purchase ledger. The stage bar (Draft, Review, Approved, Ordered, Received) sits flush on the order table. A date range filters the sheet. An order opens to a description list and its lines.

Signed in as Gita Poluru, Buyer.

Pages: Orders, order detail, Suppliers, Approvals, Receipts, Settings.

Stack: Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Accent `#CA8A04`.

Dev server on port 5226. Open http://localhost:5226/purchasewell/orders.
