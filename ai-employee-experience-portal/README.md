# Hearth

Employee experience portal for services, feedback, announcements, and workplace resources.

Light theme with brand color `#FF6500`. Orange fills use dark ink so labels stay readable. Fonts are Roboto and Lato. Signed in as Meera Poluru.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5205/experience/overview](http://localhost:5205/experience/overview).

## Pages

- Overview
- Services and service detail
- Feedback
- Announcements
- Resources
- Search
- Settings
