# Watchline

Watch desk for incidents, assets, access reviews, and changes.

The sidebar is Incidents, Assets, Access, Changes, and Settings. Accent `#1E3A8A` is used on buttons, focus, and the active nav. The page background stays white.

```bash
npm install
npm run dev
```
