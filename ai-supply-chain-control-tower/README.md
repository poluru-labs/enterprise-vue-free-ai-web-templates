# Stockwell

Control sheet for orders, suppliers, and three warehouses.

The sidebar is Tower, Orders, Suppliers, Sites, and Settings. Accent `#047857` is used on buttons, links, and the active nav. The page background stays light. The stat strip and the order tables share one width.

```bash
npm install
npm run dev
```
