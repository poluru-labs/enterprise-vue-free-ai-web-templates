# Allyard

Partner directory. Each firm is a wide card with its lead, region, and tier. A switch filters Registered, Select, and Premier. The profile opens in a drawer.

Signed in as Asha Poluru, Alliance lead.

Pages: Partners, partner profile, Deals, Enablement, Contacts, Settings.

Stack: Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Accent `#0F766E`.

Dev server on port 5225. Open http://localhost:5225/allyard/partners.
