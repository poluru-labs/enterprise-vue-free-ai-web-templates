# Hirewell

Recruiting desk. Each open role shows a stepper for Applied, Screen, Interview, and Offer. Candidates for that role sit in a table under the stepper. Interview feedback is a rating.

Signed in as Ishaan Poluru, Recruiting lead.

Pages: Roles, role detail, Candidates, candidate detail, Interviews, Offers, Settings.

Stack: Vue 3, Vite, TypeScript, vue-router, and `@poluru-labs/enterprise-design-system-vue`. Accent `#BE123C`.

Dev server on port 5229. Open http://localhost:5229/hirewell/roles.
